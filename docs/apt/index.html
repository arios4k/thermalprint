ThermalPrint

Design, prepare and print thermal labels on Linux. Import shipping labels, crop and arrange pages, or create custom labels with real barcodes and QR codes.

Read the user manual: a step-by-step guide to every feature, with screenshots.

Install

For Debian, Ubuntu and derivatives on 64-bit Intel/AMD (amd64), add the signed APT repository:

sudo apt update
sudo apt install curl
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://arios4k.github.io/thermalprint/key.asc \
  | sudo tee /etc/apt/keyrings/thermalprint.asc >/dev/null

echo 'deb [arch=amd64 signed-by=/etc/apt/keyrings/thermalprint.asc] https://arios4k.github.io/thermalprint/ stable main' \
  | sudo tee /etc/apt/sources.list.d/thermalprint.list >/dev/null

sudo apt update
sudo apt install thermalprint

Updates arrive with sudo apt upgrade.

Install on Fedora

For Fedora 44 and 45 on 64-bit Intel/AMD, from the community Copr repository:

sudo dnf install dnf5-plugins
sudo dnf copr enable arios/thermalprint
sudo dnf install thermalprint

Copr is separate from Fedora’s official package repositories.

Set up

Configure your thermal printer in your desktop’s printer settings, then open ThermalPrint from your applications menu. Choose a template, create a custom label, or import an existing shipping label. Check the paper size and print preview before printing.

Packages include CUPS client tools and Poppler PDF utilities. Documents are processed locally on your computer.

Uninstall

Debian / Ubuntu:

sudo apt remove thermalprint
sudo rm /etc/apt/sources.list.d/thermalprint.list /etc/apt/keyrings/thermalprint.asc

Fedora:

sudo dnf remove thermalprint
sudo dnf copr disable arios/thermalprint

Source, documentation and issues: github.com/arios4k/thermalprint. Standalone packages: latest release. The APT repository is signed; the public key is key.asc.
