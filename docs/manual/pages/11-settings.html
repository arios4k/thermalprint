ThermalPrint has no settings window. It remembers your choices as you make them, in small text files in your home folder. You can read or delete them at any time.

To start fresh, quit ThermalPrint and delete these files. A damaged or hand-edited settings file is checked when it is read: impossible values are corrected, and an unreadable file is ignored.

On Windows, configuration files use %APPDATA%\ThermalPrint\ThermalPrint\config, designer recovery uses %LOCALAPPDATA%\ThermalPrint\ThermalPrint\data, and app.ron uses %APPDATA%\org.thermalprint.ThermalPrint\data. On Linux, custom XDG_CONFIG_HOME and XDG_DATA_HOME values can change the paths shown above.

Disable Start at login before removing settings if you also want to remove ThermalPrint's startup entry. With background mode enabled, closing the window does not quit the process: choose Quit from the app or tray menu before managing its files.

A damaged duplicate-protection file pauses automatic printing instead of being ignored, so an unreadable record cannot silently cause repeat jobs. Review previous jobs before using Clear duplicate protection…. Clearing print history does not clear these records.

Recent documents and recent prints contain file names and locations, and a printed design's contents. Use Clear history in Print Center before sharing your settings folder.

Privacy

  • Your labels stay on your computer. Documents are processed locally. ThermalPrint does not upload anything and does not connect to any marketplace or carrier account.
  • There is no tracking, analytics, or account.
  • The app opens your web browser only when you press a link or the Help button.
  • When printing, labels go to the printer system on your computer (or the network printer you chose).

Environment variables

VariableEffect
THERMALPRINT_PDFIUM_DIRFolder containing a custom PDFium library. Use libpdfium.so on Linux or pdfium.dll on Windows. The Windows package already includes PDFium.
CUPS_SERVEROn Linux, use a different CUPS server. A path to a socket is supported. Remote servers are not used for reading printer details.
RUST_LOG=thermalprint=debugPrint diagnostic details to the terminal. Keep logs private; they can include file paths.
LC_ALL, LC_MESSAGES, LANGUAGE, LANGSet the locale on Linux. On Windows, ThermalPrint reads your Windows regional settings. The interface supports Spanish, German, French, and English.
