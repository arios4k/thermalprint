ThermalPrint has no settings window. It remembers your choices as you make them, in small text files in your home folder. You can read or delete them at any time.

What is remembered

WhatRemembered?
Selected printer, media, resolution, size, DPI, rotation, margin, scale, copiesYes, and kept separately for each printer.
Alignment offsetsYes, per printer.
Theme (System, Light, Dark)Yes.
Sidebar collapsed or expandedYes.
Watch folder and whether it is onYes.
Recent documents (up to 8 file locations)Yes.
Recent prints (up to 50)Yes, in a separate file.
Window size and positionYes.
The print queue in Import & ConvertNo. It is empty each time you start.
Your label designsOnly as the .thermalprint files you save yourself, plus a recovery copy while changes are unsaved.
Your templates, logos, fonts, and address bookYes, in the folders listed below.

To start fresh, quit ThermalPrint and delete these files. A damaged or hand-edited settings file is checked when it is read: impossible values are corrected, and an unreadable file is ignored.

Recent documents and recent prints contain file names and locations, and a printed design's contents. Use Clear history in Print Center before sharing your settings folder.

Privacy

  • Your labels stay on your computer. Documents are processed locally. ThermalPrint does not upload anything and does not connect to any marketplace or carrier account.
  • There is no tracking, analytics, or account.
  • The app opens your web browser only when you press a link or the Help button.
  • When printing, labels go to the printer system on your computer (or the network printer you chose).

Environment variables

VariableEffect
THERMALPRINT_PDFIUM_DIRFolder containing libpdfium.so, to use PDFium instead of Poppler.
CUPS_SERVERUse a different CUPS server. A path to a socket is supported; remote servers are not used for reading printer details.
RUST_LOG=thermalprint=debugPrint diagnostic details to the terminal. Keep logs private; they can include file paths.
LC_ALL, LC_MESSAGES, LANGUAGE, LANGYour system language, which ThermalPrint follows (Spanish, German, French; otherwise English).
