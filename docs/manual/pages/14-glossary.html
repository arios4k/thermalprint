The same terms are also explained inside the app: open the main menu (☰) and choose Printing terms.

TermMeaning
Alignment offsetA small shift, in millimeters, that moves printed content to correct a printer that feeds labels off-center.
Banner pageA page some print systems add before or after a job. ThermalPrint turns it off.
Auto-lengthA label setting for continuous rolls: the printed length follows the content instead of a fixed height.
BatchPrinting many labels in one go, either from a queue of files or from a spreadsheet merged into a design.
ClippingContent that would be cut off at the paper edge. ThermalPrint blocks printing when it happens.
Code 128, Code 39, EAN, UPC, ITF, CodabarLinear barcode types. See the Barcode reference.
ConfinementThe sandbox a Snap runs in, which limits what files and devices it can reach.
CopiesHow many identical labels to print for each label.
CSVA plain text table with values separated by commas (or semicolons or tabs). Spreadsheet programs export it.
CUPSThe Common UNIX Printing System: the standard Linux service that manages printers and print jobs. ThermalPrint prints through it.
Data MatrixA small square 2D barcode, good for tiny labels.
DesignA label you created in the Label Designer, saved as a .thermalprint file.
DPIDots per inch: how many printed dots fit in an inch. Common thermal printers are 203 or 300 DPI.
DriverThe software that translates a print job into commands your printer understands.
FNC1A control character in GS1 barcodes. It marks the start of GS1 data and ends a variable-length field.
GS1, application identifier (AI)The global standard for supply-chain barcodes. An AI is the number in brackets, such as (01) for a product number, that says what the value after it means.
GTINGlobal Trade Item Number: the number behind a product barcode such as EAN-13 or UPC-A.
MediaThe paper (here, label) size the printer driver offers, such as 4 × 6 in.
ObjectOne item on a label: a text box, barcode, QR code, shape, or image.
PlaceholderA ${name} marker in a design that is replaced with a value when the label is drawn.
PortalA desktop service that lets a sandboxed app open or save files you choose, such as the file chooser.
PPDA file that describes a printer's features and paper sizes to CUPS.
ProfileThe settings ThermalPrint remembers for one printer.
QR codeA square 2D barcode that can hold web addresses and text.
Quiet zoneThe blank margin around a barcode that a scanner needs to find its edges.
Queue (print queue)The list of labels waiting to print in Import & Convert. Also, a printer's name in CUPS.
Raw queueA CUPS queue that passes data straight to the printer without a driver. Needed for raw ZPL.
Serial numberA counting number printed with ${serial}.
SSCCSerial Shipping Container Code: an 18-digit number that identifies one pallet or parcel.
Thermal printerA printer that makes marks with heat on special paper, so it needs no ink or toner.
ThresholdTurning every pixel fully black or white. It can harm thin barcode bars.
Watch folderA folder ThermalPrint checks for new label files to add to the queue.
ZPLZebra Programming Language: commands that some label printers understand directly.

Frequently asked questions

Does ThermalPrint work with my printer?

If CUPS can print to it and its driver advertises your label size, yes. Zebra, Rollo, Brother, ORGSTA, Dymo, Munbyn, Phomemo, and many other label printers work this way. Raw ZPL needs a printer that understands ZPL.

Can it print postage?

No. ThermalPrint prepares and prints labels. It does not buy postage or create tracking numbers, and it does not connect to carrier or marketplace accounts.

Why does the preview differ from my printed label?

The preview shows exactly what is sent. Differences come from the printer: its calibration, darkness, margins, or the loaded roll. Use the alignment test and print one label before a roll.

Is it free?

Yes. ThermalPrint is open source under the MIT license, created by Alexis Rios-Negron. If it is useful to you, you can support its development, star it on GitHub, or report a bug.

How do I change the language?

ThermalPrint follows your system language (Spanish, German, or French; otherwise English). Change your system language and restart the app.
