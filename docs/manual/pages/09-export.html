Instead of printing, you can save a finished label as a file to inspect, archive, email, or print later. Exports come from the same full-resolution pipeline as printing, not from a screenshot of the preview, and the original file is never modified.

Exporting works without a printer. A file chooser asks where to save, and the file is written safely: it is created under a temporary name and moved into place only when complete, so a failed export never leaves a half-written file.

The formats

FormatWhat you getGood for
PDFOne page whose size is exactly your label size. The page contains the finished label as an image at the chosen DPI.Archiving, emailing, or printing from another program.
PNGThe label as an image at the chosen resolution (203, 300, or 600 DPI), with the DPI recorded in the file.Previews, documents, and other software.
SVG (designs)An SVG document with the label embedded as a raster picture. It keeps the physical size, but it is not editable vector artwork.Placing a label in a page-layout program at the right size.
ZPL (designs)A text file of ZPL II commands that draws the label as a bitmap.Zebra-compatible printers that you feed ZPL directly.
TSPL (designs)A file of TSPL commands that sets the label size and draws the label as a bitmap.TSPL printers, such as many low-cost 4 × 6 shipping label printers, that you feed TSPL directly.

With rotated printing on, ZPL and TSPL are rotated 90° like a print, so it fits the label stock. PDF, PNG, and SVG keep the design the way it looks on the canvas.

Because exports are bitmaps, text in a PDF or SVG cannot be selected or searched. Keep the .thermalprint file if you want to edit the label later. Exports never include the label footer; it is added only when a design prints.

Printing raw ZPL or TSPL

Most printers are used through their normal driver, and ThermalPrint sends them a PDF. Some label printers also accept their own command language directly through a raw queue, which skips the driver. Zebra-compatible printers use ZPL. Many low-cost 4 × 6 shipping label printers use TSPL; check the printer's specifications or manual to find out which one it speaks.

  1. Create a raw queue for the printer in your system's printer setup (a queue that passes data straight through). A normal PDF queue will not work for raw printing.
  2. In the Label Designer, open Export and choose Print using raw ZPL or Print using raw TSPL. Print through the printer driver turns raw printing off again.
  3. Choose that raw queue in Print Center and press Print.
  • The status bar reminds you to verify printer compatibility and the loaded label size.
  • ZPL and TSPL from ThermalPrint are a bitmap of the whole label, so fonts and barcodes look exactly as in the preview.
  • TSPL sets the label size but leaves the gap or black-mark setting to the printer, so calibrate the printer for your labels first, using its feed button or its own utility.
  • The alignment offset does not apply to raw printing; adjust position in the design instead.
  • Batch printing and reprints from print history use the same language the label was sent in.

Sending ZPL or TSPL to a printer that does not understand it can print pages of garbled characters. Only use a raw language your printer supports.

Limits

  • Output larger than 45 megapixels is refused: US Legal fits at 600 DPI. For larger paper, lower the DPI or the size.
  • A label that would be clipped cannot be exported until you fix the layout.
  • A design where a barcode or QR code overlaps another object cannot be exported either. Move the objects apart; see When a code overlaps another object.
