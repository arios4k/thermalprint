Import & Convert turns a downloaded label into something your thermal printer can print at the right size. The label file you open is never changed; ThermalPrint works on a copy in memory.

Adding labels

You can add labels three ways:

  • Press Add labels… or Ctrl+O and choose one or more files.
  • Drag files from your file manager onto the window.
  • Set up a watch folder so new downloads appear by themselves. Tick Move printed labels to a Processed folder there to have each printed label leave the queue and move into a Processed subfolder.

Supported files: PDF, PNG, JPEG, TIFF, BMP, and WebP. Each page of a multi-page PDF becomes its own entry in the queue. Files can be up to 256 MB and 45 megapixels. If a PDF is encrypted or damaged, export it again from the place you got it.

The print queue

Everything you add joins the print queue. The queue shows Label 1 of 3 with previous and next buttons, and a Queued labels list.

ControlWhat it does
Previous / nextMove between labels in the queue.
Move up / move downChange the printing order.
Remove (trash)Take the selected label out of the queue. The file itself is not deleted.
Print all N labels in orderSend every label to the printer, one after another, in queue order. See below.
Printed labels (with Move printed labels to a Processed folder on)After you print, the label leaves the queue, its file moves to the Processed folder inside your watch folder, and the next label is shown. The counters follow along. See Watching a folder.
Page boxFor a multi-page PDF, jump to another page.

Each label remembers its own crop, extraction mode, and review state. The queue lives in memory for the current session; it is not restored when you quit. Recent file names are remembered, so you can reopen files from Home.

Step 01: Extract

Most carrier PDFs have a label plus instructions, a receipt, or a lot of empty space. Extract chooses which part to print.

Automatic

ThermalPrint looks for printed content and proposes a crop with a small safety border. When one region looks like a label and another looks like an instruction block, it keeps the label and drops the instructions. If several regions look equally likely, it keeps the whole page until you choose. A Queue all N detected regions button turns each region into its own queue entry, useful for a sheet that holds several labels. Automatic is layout analysis, not a carrier-specific recognizer: always review it.

Manual

Switch to Original / crop in the preview. Drag on the page to draw a crop, drag inside it to move it, and drag a corner to resize. The crop is described on the original page, before any rotation. Reset to entire page starts over.

Full page

Prints the whole page. Use it when the file is already a label or when the edges are unclear.

Reviewing the crop

When a crop leaves something out, ThermalPrint asks you to confirm it before you can print. Check the address, tracking number, carrier marks, and the empty margin (the quiet zone) around each barcode, then tick I checked the crop and barcode edges. Print all needs every queue entry to be reviewed.

Step 02: Paper and layout

SettingWhat it does
Size presets4 × 6 in, 4 × 4 in, 2 × 1 in, and 100 × 150 mm. 4 × 6 inches is the standard shipping label.
W and HA custom width and height in millimeters (10 to 500).
Swap portrait / landscapeSwaps width and height.
RotateTurns the label 0°, 90°, 180°, or 270°. Use it when your printer feeds labels sideways.

Actual sizeUses the source's real physical size. Images without a reliable size are treated as 300 DPI.
Custom scaleA percentage from 10 % to 400 % of the actual size.
MarginEmpty space around the label, 0 to 20 mm.
Black-and-white thresholdTurns every pixel fully black or fully white. Off by default because it can damage thin barcode bars. Turn it on only if a gray label prints faintly, and test the barcode.

Blocked on purpose. If the content would be cut off (clipped) at the chosen size, printing and exporting are blocked and a warning explains why. Use Fit within paper, rotate, reduce the scale, or choose larger paper.

ThermalPrint also warns when the label is shrunk a lot (small text and barcode bars can become unreadable) or when low-resolution pixels are enlarged. Enlarging cannot restore detail that is not in the file.

Step 03: Print and export

  1. Choose the printer. A short hint under it says whether it looks like a label printer. This is a best guess from the name and media, not a guarantee.
  2. Choose the media size the printer advertises, matching the stock you loaded. See Print Center for how media works.
  3. Optionally open Advanced driver resolution to pick a resolution your printer offers.
  4. Set the number of Copies.
  5. Press Print label (Ctrl+P).

If the label came from your watch folder and Move printed labels to a Processed folder is ticked, a successful print also moves the file into Processed and shows the next label. Labels you added by hand from other folders stay where they are.

The PDF and PNG buttons save the finished label as a file instead; see Exporting. Job status asks the printer system what is waiting.

The Print button stays disabled until the label has rendered, the crop is reviewed, a printer and matching media are chosen, and nothing is clipped. The status bar and the notice in Print Center say what is still missing.

The preview

The right side shows the label two ways. Use the buttons at the top:

  • Original / crop shows the whole source page and your crop, for drawing and adjusting.
  • Thermal label shows the final result at print resolution, exactly as it will be sent.
  • The zoom buttons and Fit change the preview size.

Printing several labels

Add all the files, review each one, then press Print all N labels in order. The labels are submitted one after another in queue order. The batch stops at the first problem (a file that can no longer be read, a layout error, or a printer error) and tells you how many were sent. Paper size, resolution, rotation, margins, scale, copies, printer, and media are shared by the whole batch.

Submission order is not a promise about physical printing. Use Job status and look at the printer to confirm what came out.

If you want to print many different values on one design, such as a list of customers, use Batch printing from CSV instead.

Tips for good barcodes

  • Leave a clear margin (quiet zone) on both sides of every barcode.
  • Keep thresholding off unless you need it.
  • Prefer Fit within paper on a source that is already label-sized.
  • Scan a test label with your phone or scanner before printing a roll. ThermalPrint does not read imported barcodes or measure print quality.
