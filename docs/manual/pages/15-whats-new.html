This page lists what changed recently and links to the full explanation of each tool. Your version is shown in ☰ → About ThermalPrint.

Version 0.18.0

Windows printing now follows the selected label media and the printer driver's actual printable area.

  • Alignment tests that respect printer margins. The test pattern uses the selected stock, orientation, real printer DPI, and Windows driver's imageable area. Its marks stay inside printable margins; genuine clipping still has an actionable explanation.
  • Media and output stay in sync. Changing the printer, label size, or orientation updates the matching media and page dimensions. Windows receives the selected paper size and orientation explicitly, and normal output is fitted to the selected media without stretching or cropping.
  • Background printing stays in the tray. Closing the main window keeps background printing active, and a later print error no longer brings the window back.

Version 0.17.0

Easier printer setup, stock profiles that are clear to use, and every paper size your printer supports.

  • A step-by-step setup assistant. Four numbered steps, Printer, Paper or label size, Alignment, and Save, each with its own controls, and a finish page that confirms the profile was saved and is now active. See Printer setup assistant.
  • Stock profiles, clearly. An Active profile menu in Print Center and Import & Convert always shows the profile in use and switches to another in one step, across printers. The imported label and the design in the Label Designer take the profile's label size automatically. Update a profile after changing it, delete profiles you no longer need, and keep as many per printer as you like. Profiles for other printers no longer disappear from the list, and saving can no longer silently replace one. See Stock profiles.
  • Any paper size the printer supports. Office printers offer all their paper, including Letter and Legal, in Print Center, Import & Convert, the Label Designer's new Printer paper size, and Print on a sheet…. Choosing a size sets the output to match. Pages up to US Legal print at 600 DPI.
  • No more waiting on a stuck printer. Printers are found in the background and all at once, and every call to the printing system has a time limit. A printer that is paused, offline, or not answering is listed with a note instead of freezing the app.

Version 0.16.0

A redesigned, better organized interface. Every feature is still there; it is grouped so each screen shows what you need for the task in front of you.

  • A new look of its own. A teal accent taken from the app icon, a clean interface font (Segoe UI on Windows, Inter or Noto Sans on Linux), flatter cards, and one consistent corner radius. ThermalPrint no longer imitates one desktop's style.
  • Window controls that match your system. Windows gets its familiar wide minimize, maximize, and close buttons, with a red close button; Linux gets small rounded buttons. Window and screen titles now sit at the left. See The window at a glance.
  • An icon on every button, with its name written beside it, so actions are quick to find and easy to tell apart.
  • Label Designer toolbar in groups. Document, edit, zoom, and the View, Export, and new Label menus, with Print alone at the right. Label footer…, Check barcodes, and Focus canvas are now in the Label menu, and the zoom percentage resets to 100 % when clicked. See The toolbar.
  • Properties panel tabs. Object, Label, and Footer replace one long scroll; the Object tab opens by itself when you select something. See The properties panel.
  • One note line under the canvas. The most important note shows; More notes lists the rest. See Notes under the canvas.
  • Print Center tabs: Printer, Label stock, and Recent prints. See Print Center.
  • Import & Convert tabs: Label for the label in front of you, and Automation for background printing, the watch folder, and automatic printing. The Watching line stays visible on both. See The sidebar.
  • Compact layout in the main menu for small screens. See The main menu.
  • Accessibility. A visible focus ring on every control, tabs announced as tabs with their selected state, a name for every icon button, and text that meets WCAG AA contrast in light and dark mode, checked by the app's tests. See Accessibility.

Version 0.15.0

  • The label footer moved to the Label Designer. Turn it on, edit it, align it, and reset it in the new Label footer section of the properties panel, or press Footer in the Designer toolbar. Print Center no longer has footer controls. See Label footer.
  • Footer alignment. Place the whole footer, QR code included, at the left, center, or right of the bottom edge. It goes only into blank space inside the printable area, the label size never changes, and a note explains what was left out when it does not fit.
  • Imported shipping labels never get a footer. Direct prints, reprints, and automatic printing of imported labels carry no text, QR code, or promotional content from ThermalPrint, and the footer setting has no effect on their layout, scale, or output.
  • Overlap warning. As soon as a barcode or QR code overlaps another object, a warning names it and Print turns off until the objects are apart. The canvas stays visible and editable, so you can move, resize, or reorder the objects without undoing. See When a code overlaps another object.
  • More shipping symbols. Do not stack, Keep cool, Keep out of sunlight, and Package join the Symbols and logos picker. See Symbols and logos.

Version 0.14.0

  • Label footer. Print a small message, such as Printed with ThermalPrint, along the bottom of every label, with an optional QR code before it that links to this manual or to your own site. It sits at the bottom-left, away from carrier tracking barcodes. The footer is off by default. In version 0.15.0 the footer moved to the Label Designer and no longer applies to imported labels; see Label footer.
  • Labels are never shrunk for the footer. The footer prints only in blank space at the bottom of a label, so every barcode prints exactly as it would without it. When the QR code does not fit, only the message prints; when the message does not fit either, the footer is left out and a note says why. Exported files never include it.
  • More accurate automatic crop. A section with its own barcode now stays with the label. FedEx Ground Economy labels keep their lower USPS Deliver to section and tracking barcode, while printed instructions, such as those on Vinted FedEx labels, are still cropped away. See Importing labels.
  • Windows on the project page. The project page now shows how to install ThermalPrint on Windows 11 from the Microsoft Store.

Version 0.13.1

  • Startup tray recovery. Linux retries when its status tray is not ready at login, using a readiness query compatible with strict Snap confinement. Windows checks notification-icon registration and retries a failed registration. Background startup hides after the first frame and tray initialization; an unavailable tray leaves a visible fallback. Opening or interacting with the app yourself keeps it visible. See Background printing.
  • Repeated login activation. Launching another background instance no longer brings the existing window forward. Opening a saved label still brings it back for review.
  • Main menu. Help & Manual replaces User manual, and a separator places Quit apart from the help and About actions.

Version 0.13.0

  • Background printing. Optional tray controls let folder watching and automatic printing continue after closing the window. Startup at login is optional. A supported desktop tray is required. See Automation.
  • Duplicate protection. Automatic printing remembers file contents across renamed downloads and restarts. Uncertain submissions pause for review. Manual printing remains available when another copy is intended.
  • Reprint from history. Review and confirm a recent job using its recorded printer settings. Changed or missing source documents require review. See Print Center.
  • Printer setup and stock profiles. A guided assistant helps match dimensions, media, DPI, and alignment. Save named stock profiles for each printer.
  • Check barcodes. Validate generated code content, size, and clear space before printing. Check a physical print with your scanner. See Label Designer.
  • Four new templates. Cable flag, Price and barcode, Shelf barcode, and Small product QR have matching icons in the template menu.

Version 0.12.1

  • Label Designer layer controls. Forward is disabled when the selected object is already at the front, and Backward is disabled when it is already at the back. Each move takes one undo step. Redo reapplies the move. See The properties panel.

Version 0.12.0

  • Windows 11 x64 edition. The first Windows build adds native Windows printing and includes PDFium for PDF import. ThermalPrint is available in the Microsoft Store. See Windows setup.
  • Labels saved while ThermalPrint was closed. The watch folder used to ignore everything already in it when the app opened, so a label downloaded while ThermalPrint was closed was never picked up. Now ThermalPrint remembers when it last checked the folder, and when it opens it adds the labels saved since then, with a message saying how many. With Print labels automatically on, they print like any new label, each after the Cancel countdown. Files that were already there when you turned watching on are still ignored. See Watching a folder.

Version 0.11.1

  • Easier to find. Searching for words like shipping label, thermal printer, 4x6, barcode, ZPL, or Vinted now finds ThermalPrint in your software center and in your desktop's app search. Nothing else changes in the app.

Version 0.11.0

  • Five new built-in fonts. Condensed, Monospace, Serif, Headline, and Rounded join the default font. They come with ThermalPrint, so a design prints the same on every computer. See Fonts.
  • Your computer's fonts. Label text can use the fonts installed on your computer, found by name with a search box. Fonts made only for other writing systems are left out.
  • Choose a font. The font button of a text object opens a window that shows each font's name in that font, opens at the text's current font, and closes when you pick one.
  • Your last font is remembered. New text starts with the font you chose last, or the default font until you choose one. Bold uses a font's bold face when it has one.

Version 0.10.0

  • Rotated printing. An optional setting in the Label Designer's Label setup: tick Rotate 90° when printing to design a wide label on its side, so the text reads straight while you work, and it is rotated 90° when it prints to fit the label stock as loaded. A banner over the canvas says so, an As printed card shows how the label comes out of the printer, and Rotate the other way turns it the other direction. Printing, numbered runs, batches, sheets, and ZPL are rotated; PDF, PNG, and SVG exports are not. See Rotated printing.

Version 0.9.2

  • 0.9.1 for Debian and Ubuntu. The 0.9.1 changes below did not reach the APT repository; 0.9.2 brings them there. Nothing else changes in the app. The screenshots in this manual show the new title bar.

Version 0.9.1

  • A title bar like other GNOME apps. The app name and the main menu (☰) sit above the sidebar, the name of the area you are in is centered above the workspace, and the window buttons are small and round. See The window at a glance.
  • Light and dark follow your system. The Appearance choice is gone from the main menu: ThermalPrint is always light or dark like your desktop. See Light and dark mode.

Version 0.9.0

  • Print labels automatically. A new option under Watch a folder, off by default and remembered, prints single-page labels whose crop needs no review by themselves when they land in the watch folder. Each waits 5 seconds with a Cancel button, a Pause auto-print button stops everything, Most per minute limits bursts, Only files named filters by name, every file prints once, and a failure pauses automatic printing with a message. The first time you turn it on, a warning explains the risk and recommends a folder used only for labels. See Printing labels automatically.
  • The printable area explains itself. When Show printable area has nothing to shade, a short note says why, for example that the printer's driver reports no unprintable border, which is common for thermal printers.
  • Safe margin. View → Safe margin (also in Print Center) keeps content a set distance from the edge, from 0 to 10 mm, and is remembered for each printer. It is shaded on the canvas and objects inside it are flagged, even when the driver reports no border. See Safe margin. The shading is also stronger.

Version 0.8.0

  • A logo in the middle of a QR code. Select a QR code, press Add logo… under Logo in the center, and choose a picture or one of your saved logos. The code switches to the highest error correction and is never smaller than 37 × 37 squares, and the clear box for the logo is limited to 30 % of the code's width, which is checked by decoding rendered codes in the app's tests. A red note says how wide to make the code so the logo scans, and a code that is too small for a logo is refused instead of printed unreadable. See A logo in the middle.

Version 0.7.2

  • The app always opens on Home. Version 0.7.0 jumped straight to Import & Convert when a saved queue was waiting. Now Home is always first, and the Restore your last queue? card appears there with large Restore and Discard buttons. See Keeping the queue between sessions.

Version 0.7.1

  • A more modern, larger Home screen. The two start cards are bigger and are buttons all the way across, with a tall colored button and an arrow. Templates are large icon tiles, recent documents are clickable rows, and the printer is a status chip at the top right. See The Home screen.
  • A Print button next to the preview. A new row above the preview has previous / next with a Label 2 of 5 counter, a Reviewed checkbox, and a green Print button with a printer icon, so you no longer scroll to the bottom of the sidebar. When Print is unavailable, point at it to read why. It does the same as Print label in the sidebar and Ctrl+P. See The preview.

Version 0.7.0

The watch folder

  • A visible Watching indicator. A green dot, the word Watching, and the folder's name stay at the top of the sidebar while watching is on. If the folder cannot be read, a red message says why, watching keeps trying, and Turn watching back on restarts it. See Watching a folder.
  • Undo for Processed. After labels are moved, an Undo button is offered for 12 seconds, and Add from Processed… brings back any older label.
  • A printer for watched labels. Choose one printer for labels from the watch folder; the app switches to it automatically.

The print queue

  • Thumbnails for every queued label, and Alt+← / Alt+→ to move between labels. Ctrl+Enter prints the current label and shows the next. See The print queue.
  • The queue is remembered. After a restart or crash you can Restore or Discard it.
  • Keep going if a label fails lets Print all skip a failed label and carry on, and Skip review for automatic crops removes the review wait for layouts you trust.
  • Will print summary: the copies, size, printer, and resolution are shown just before the Print button.

Messages and getting started

  • Messages that stay. Results and errors appear in a message box for a few seconds, and the Messages button beside the status bar lists the last 30. See The workspace.
  • Get ready to print. New users see a short checklist on Home until a printer and media are chosen.
  • Every screen text is translated. A test now fails if a new label has no Spanish, German, or French translation.

Version 0.6.3

  • Move printed labels to a Processed folder. A new checkbox under Watch a folder moves each label you print from the watch folder into a Processed subfolder and takes it out of the queue, then shows the next label. It is off by default. See Automation.
  • Fewer missed labels. The watch folder no longer ignores a new file that reuses the name of one you imported earlier, and it copes with very large folders.

Version 0.6.2

  • Previews of saved labels in your file manager. The Debian and Fedora packages now include a thumbnailer, so a .thermalprint file shows a picture of the label instead of a generic icon. The file manager runs thermalprint --thumbnail for you; it draws the label without opening a window. Thumbnails appear after the package is updated and the file manager is restarted. See Opening saved designs.
  • Icon fix for the Snap. The register helper now also copies the file icon into your current icon theme's folders, which fixes themes such as Zorin that showed a generic icon. Run it once more after updating.
  • Works with regular printers. The documentation and store descriptions now say that, although ThermalPrint is made for thermal printers, it also works with laser and inkjet printers (see the FAQ).

Version 0.6.1

  • Delete buttons. The delete buttons in the address book, logo, and template lists are now trash icons. Every icon button also has an accessible name for screen readers.
  • Symbols in dark mode. Symbol and logo previews sit on white so they are visible in the dark theme.
  • File icon. Saved .thermalprint files show the ThermalPrint icon in file managers. Snap users run the register helper once more after updating.
