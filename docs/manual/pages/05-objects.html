A label is made of objects. This page covers each kind, then the things they all share: position, size, rotation, and order.

Fonts

Select a text object and click its font button (it shows the current font) to open Choose a font. Each font's name is drawn in that font, so you can see how it looks, with its plain name on the right. Type in Search fonts to narrow the list by name, then click a font to use it; the window closes. Esc or the window's close button closes it without changing the font. The list has three groups:

{{figure:designer-fonts|The Choose a font window with a search box, and each font's name drawn in that font: the built-in fonts and the fonts on this computer|Choose a font: each name is drawn in its own font.}}
GroupFontsOn another computer
Built inDefault (DejaVu Sans), and five fonts chosen for labels: Condensed (fits more text on a line, for long addresses and product names), Monospace (every character the same width, for SKUs, order numbers, and serials), Serif (a classic look for name labels, jars, and gifts), Headline (tall and heavy, for words like FRAGILE or SALE), and Rounded (a friendly look for price tags).They come with ThermalPrint, so a design prints the same on every computer.
Your fontsFonts you added with the T button next to the list, from a .ttf or .otf file. They are copied into ThermalPrint's fonts folder.Add the same font file there too.
On this computerThe fonts installed on your computer. Type in Search fonts to find one by name.Install the same font there too.

A design stores only the font's name. When a font from Your fonts or On this computer is chosen, a note under the list reminds you that another computer needs it installed. If a design's font is missing, the default font is used and a note says so.

Bold works with the default font, with Condensed, Monospace, and Serif, and with a computer font whose family has a Bold style. Headline and Rounded have one weight; for your own fonts, add a bold file.

Some installed fonts can change their weight or width (variable fonts). ThermalPrint draws them in their standard style, so each is listed once. Font collections (.ttc) and bitmap fonts are not listed.

Unless you tick Wrap long lines, text does not wrap: each line stays on one line, so press Enter where you want a new line. Anything that extends past the box is cut off at its edge, so make the box larger, tick Shrink to fit the box, or make the text smaller if letters disappear. The font is built in and does not depend on the fonts installed on your computer, so labels look the same on every machine.

Dynamic text: date and serial number

Two special words are replaced when the label is drawn, in text, barcodes, and QR codes:

Write thisPrinted as
${date}Today's date, like 2026-11-07.
${date:%d/%m/%Y}Today's date in a format you choose, like 07/11/2026. The codes are the usual %Y year, %m month, %d day, %H hour, %M minute. A format that is not valid is left as written.
${serial}The serial number from Label setup → Serial variable (1 to start). In a batch, it counts up by one for each row.
${serial:4}The serial number padded with zeros to 4 digits, like 0007. The width can be 1 to 12.

For example, a barcode with the value INV-${serial} encodes INV-1. The hint above the text box reminds you: ${date} and ${serial} are dynamic. Words in a batch, such as ${Name}, are covered in Batch printing.

Address book

The address book tool in the palette (the card with a person) lists the addresses you saved. Click one to add it to the label as a text block; the trash button beside it removes it. To add one, select a text object and press Save to address book; it is named after its first line, and saving the same name again replaces it. The book holds up to 500 addresses and is stored in addresses.json (see Where your data lives).

Barcodes

Click the barcode tool, type the value in Enter your real product code or reference, and choose the type from the dropdown. Hovering a type explains it.

  • Show value below bars prints the readable text under the bars.
  • Make the object wide enough: if the bars would be too thin to print at the selected resolution, you see Barcode is too narrow. Widen the object or use a shorter value.
  • Values longer than 2,048 characters are refused.
  • Text size sets the size of the readable text under the bars, in points; Auto picks one that fits. Text above the bars moves it to the top.
  • For EAN-13, EAN-8, and UPC-A, enter the digits without the last one and ThermalPrint calculates the check digit; a hint shows the complete number that will print.

The supported types, what each accepts, and when to use them are in the Barcode reference, including GS1-128 and GS1 Data Matrix for logistics labels.

QR codes

The QR tool adds a square QR code. Type the content in QR content; it can be a web address, plain text, or several lines. QR error correction level chooses how much damage the code survives: Low, Medium, Quartile, or High. More correction makes a denser code, so keep the default unless the label will be scuffed. Keep the object square and at least about 20 mm wide for reliable scanning. If the object is too small for the amount of data, you see QR code is too small; enlarge the object. To put your logo in the middle of the code, see A logo in the middle.

A logo in the middle

How the size is kept safe

A logo hides some of the code's squares. A QR code carries extra data so that it can still be read when some squares are lost, and ThermalPrint makes sure a code with a logo stays readable:

  • The highest error correction is used. While a logo is on, the level is set to High (30 %) and the level box is greyed out.
  • The code is never too small. With a logo, the code has at least 37 × 37 squares (version 5), even for very short content such as a few letters. That also keeps the logo clear of the three large corner squares and the timing lines a scanner uses to find and measure the code.
  • The logo box has a size limit. It can be at most 30 % of the code's width, which is about 9 % of its area. The limit is checked in the app's own tests by reading rendered codes with a QR decoder, using the hardest logos (solid black, noise, a checkerboard), different amounts of content, and different print sizes. The codes still read when the logo is made 8 points larger than the limit, so the limit leaves a margin for blurred printing and ordinary phone cameras. Asking for more than the limit always gives the limit.
  • The code must be printed large enough. A code with a logo needs squares of at least about 0.4 mm. When your QR object is narrower than that, a red note under the size slider tells you how wide to make it. If the object is so small that a square would be under three printed dots, the label is not drawn and you see QR code is too small for a logo; enlarge the object or remove the logo, instead of printing a code that might not scan.

Even with these safeguards, scan one printed label with your phone before you print a whole roll. Printers, label stock, and cameras differ.

The stroke width is set in millimeters (0.05 to 20 mm). Thermal printers print only black, so use a stroke of at least 0.3 mm for lines to print crisply.

Images and logos

The picture tool lets you choose a PNG, JPEG, TIFF, BMP, or WebP file (up to 9 MB). The image is embedded in the design, so you can move the design to another computer without the original file. Resize the object to fit; the image keeps its proportions inside the box. Color images print in black and white on a thermal printer, so a high-contrast logo looks best.

Symbols and logos

The warning-triangle tool in the palette (Symbols and logos) adds ready-made shipping symbols as images: Fragile, This side up, Keep dry, Recycling, and Hazard. They are drawn in black and print crisply at any size. Under Your logos are images you kept: select an image and press Save as logo, and it joins the list for every future label (they are stored as PNG files in a logos folder, up to 60). The trash button beside a logo removes it.

Layout tips

  • Leave at least 2 mm between objects and the label edge; many printers cannot print right to the edge.
  • Use Show grid, Snap to grid, and Smart guides to line things up quickly, and the arrow keys for fine adjustments.
  • Lock the parts of a design that must not move, such as a logo.
  • Use Focus (hide the panels) to see the label larger while you arrange it.
  • Select several objects with Shift+click and press Ctrl+C and Ctrl+V to copy a whole group.
