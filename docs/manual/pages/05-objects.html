A label is made of objects. This page covers each kind, then the things they all share: position, size, rotation, and order.

Settings every object shares

SettingMeaning
X, YDistance of the object's top-left corner from the label's top-left corner, in millimeters.
W, HWidth and height in millimeters.
RotationClockwise degrees, any value including fractions. The X and Y of a rotated object describe the box that contains it.
Forward / BackwardMove the object up or down one layer. Objects higher in the stack cover those below.
DuplicateMakes a copy of the object (Ctrl+D).
DeleteRemoves it (Delete).

Copy and paste (Ctrl+C, Ctrl+V) work on one or several selected objects. Everything can be undone with Ctrl+Z.

Text

{{figure:designer-text|The Label Designer with an address text object selected and its text settings in the properties panel|A text object selected. The panel shows its text, size, bold, and alignment.}}

Click the T tool to add a text box that says Your text. Edit it in the properties panel. The address tool adds a three-line block ready for a name, street, and city.

SettingMeaning
Object text boxThe text. It can have several lines; press Enter for a new line.
Font sizeIn points, from 3 to 300. Larger numbers make taller letters.
BoldHeavier letters. Good for thermal printing, which can make thin text faint.
Left / Center / RightAlignment inside the box.

Text does not wrap by itself: each line stays on one line, so press Enter where you want a new line. Anything that extends past the box is cut off at its edge, so make the box larger or the text smaller if letters disappear. The font is built in and does not depend on the fonts installed on your computer, so labels look the same on every machine.

Dynamic text: date and serial number

Two special words are replaced when the label is drawn, in text, barcodes, and QR codes:

Write thisPrinted as
${date}Today's date, like 2026-11-07.
${serial}The serial number from Label setup → Serial variable (1 to start). In a batch, it counts up by one for each row.

For example, a barcode with the value INV-${serial} encodes INV-1. The hint above the text box reminds you: ${date} and ${serial} are dynamic. Words in a batch, such as ${Name}, are covered in Batch printing.

Barcodes

Click the barcode tool, type the value in Enter your real product code or reference, and choose the type from the dropdown. Hovering a type explains it.

  • Show value below bars prints the readable text under the bars.
  • Make the object wide enough: if the bars would be too thin to print at the selected resolution, you see Barcode is too narrow. Widen the object or use a shorter value.
  • Values longer than 2,048 characters are refused.

The nine supported types, what each accepts, and when to use them are in the Barcode reference.

QR codes

The QR tool adds a square QR code. Type the content in QR content; it can be a web address, plain text, or several lines. Keep the object square and at least about 20 mm wide for reliable scanning. If the object is too small for the amount of data, you see QR code is too small; enlarge the object.

Shapes

ShapeUse
Rectangle, ellipseBoxes, frames, and highlights. Tick Filled for a solid black shape.
LineA straight line across its box.
Horizontal and vertical dividersThin rules that separate sections of a label.

The stroke width is set in millimeters (0.05 to 20 mm). Thermal printers print only black, so use a stroke of at least 0.3 mm for lines to print crisply.

Images and logos

The picture tool lets you choose a PNG, JPEG, TIFF, BMP, or WebP file (up to 9 MB). The image is embedded in the design, so you can move the design to another computer without the original file. Resize the object to fit; the image keeps its proportions inside the box. Color images print in black and white on a thermal printer, so a high-contrast logo looks best.

Layout tips

  • Leave at least 2 mm between objects and the label edge; many printers cannot print right to the edge.
  • Use Show grid and Snap to grid to line things up quickly.
  • Use Focus (hide the panels) to see the label larger while you arrange it.
  • Select several objects with Shift+click and press Ctrl+C and Ctrl+V to copy a whole group.
