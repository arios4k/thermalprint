No printers are listed

  1. Make sure the printer is on and connected, and that it appears in your desktop's printer settings.
  2. In a terminal, run lpstat -p. If it lists your printer, press Refresh printers in ThermalPrint.
  3. If lpstat says it cannot connect, the CUPS service is not running. Start it with sudo systemctl enable --now cups.
  4. Snap: check snap connections thermalprint and see If printing is not connected.

You can still export files with no printer; see Exporting.

The Print button is disabled

Printing needs all of these. The status notice in Print Center tells you which one is missing:

  • The label has finished rendering.
  • A label with a changed crop has been reviewed (I checked the crop and barcode edges).
  • A printer is chosen.
  • A media size the printer offers is chosen. If the driver offers none, set the printer up for label stock in your system's printer settings.
  • Nothing is clipped: the content fits the paper.

Extra labels or banner pages

Some printer systems can print a banner or job sheet before and after each job. On a label roll each banner uses up a label. ThermalPrint turns banner pages off for every job it sends. If you still get extra labels:

  • Check whether the labels are really blank pages from the printer's own settings, such as a "gap detect" or "page length" option set for a different label size. Run the printer's calibration (usually a button or a button combination on the printer).
  • Check that the printer media matches the label size. A taller media size than the label feeds extra labels.
  • Print one label and look at the CUPS job in your printer settings to see how many pages it has. A single page means the printer feed is the cause.

Barcodes that do not scan

  • Turn off Black-and-white threshold in Import & Convert unless you really need it.
  • Check the print is dark enough: raise the printer's darkness or speed setting in its own driver.
  • Widen the barcode. Thin bars are the usual cause.
  • Leave empty space on both sides.
  • Use the right type for your scanner; see the Barcode reference.

Content looks blurry or jagged

Set Rendering DPI to the printer's real resolution (usually 203 or 300). If you enlarged a small low-resolution image, ThermalPrint warns that detail cannot be recovered; use a bigger source.

Getting diagnostic details

Start ThermalPrint from a terminal with extra logging:

RUST_LOG=thermalprint=debug thermalprint

For the Snap, use RUST_LOG=thermalprint=debug snap run thermalprint. Logs may include file paths, so read them before posting.
